Datenschutzrichtlinie

Kurzfassung: Standardmässig bleibt alles auf deinem Gerät. Nur wenn du den Klassenkalender freiwillig aktivierst, gehen Kalendereinträge an unseren Server – nie Noten oder Login-Daten.

Zusammenfassung in einem Satz

Panum Grades speichert alle Daten lokal auf deinem Gerät im eingebauten Speicher deines Browsers. Standardmässig werden keine Daten an einen Server übertragen.

Auf welche Daten greift Panum Grades zu?

Wenn du deine schulNetz-Notenseite besuchst, liest die Erweiterung die Notendaten, die bereits in deinem Browser sichtbar sind (das HTML/DOM). Das sind die gleichen Daten, die du mit eigenen Augen auf dem Bildschirm sehen kannst.

Diese Daten werden dann verwendet, um Berechnungen (Durchschnitte, Pluspunkte, Simulationen) lokal in deinem Browser durchzuführen.

Wo werden Daten gespeichert?

Alle Daten werden gespeichert mit:

  • Browser localStorage — nur auf der schulNetz-Domain verfügbar, beschränkt auf dein Browser-Profil.
  • Browser Extension Storage (chrome.storage.local / browser.storage.local) — lokal in deinen Browser-Extension-Daten gespeichert.

Keine dieser Speichermethoden beinhaltet einen externen Server (Ausnahme: der freiwillige Klassenkalender, siehe unten). Beide werden gelöscht, wenn du die Erweiterung deinstallierst oder deine Browserdaten löschst.

Welche Daten werden NICHT gesammelt?

  • Keine persönlichen Informationen (Name, E-Mail, Schule, Klasse)
  • Keine Nutzungsanalysen oder Telemetrie
  • Keine Cookies (wir setzen keine)
  • Keine IP-Adressen
  • Kein Browserverlauf
  • Nie Noten, Login-Daten oder schulNetz-Sitzungen

Macht die Erweiterung Netzwerkanfragen?

Standardmässig nicht. Notenrechner, Durchschnitte, Pluspunkte und alle anderen Funktionen laufen offline in deinem Browser.

Klassenkalender (freiwillig): Nur wenn du ihn aktivierst und dem Teilen zustimmst, verbindet sich die Erweiterung mit calendar.panumic.com. Gesendet werden: Kalendereinträge (Titel, Fach, Datum, Notiz), Schule und Klasse, gehashte Namen der Klassenliste und dein Kurzname (z.B. „Anna M.“). Nie gesendet werden Noten, Login-Daten oder schulNetz-Sitzungen. Du kannst den Kalender jederzeit nur lokal nutzen und mit „Meine Daten löschen“ alles auf dem Server entfernen.

Feedback-Formular: Nur wenn du im Popup aktiv Feedback abschickst, wird dein Text an ein Google-Formular gesendet.

Berechtigungen erklärt

Die Erweiterung fordert folgende Browser-Berechtigungen an:

  • storage — Um deine Einstellungen (z.B. welche Buttons aktiviert sind, Dark-Mode-Präferenz) lokal auf deinem Gerät zu speichern.
  • Host-Berechtigung für schul-netz.com — Um den Notenrechner und die Tools in die schulNetz-Seite einzufügen. Die Erweiterung aktiviert sich nur auf schul-netz.com.

Drittanbieterdienste

Panum Grades integriert keine Drittanbieter-Analyse-, Werbe- oder Tracking-Dienste.

Datenschutz für Minderjährige

Da Panum Grades keine Daten sammelt, gibt es keine besonderen Überlegungen für Nutzer jeglichen Alters.

Quellcode

Die Erweiterung ist quelloffen. Du kannst jede Aussage auf dieser Seite selbst überprüfen, indem du den Code auf GitHub liest.

Änderungen an dieser Richtlinie

Falls diese Richtlinie aktualisiert wird, werden die Änderungen auf dieser Seite ersichtlich. Da wir grundsätzlich keine Daten sammeln, sind wesentliche Änderungen unwahrscheinlich.

Kontakt

Bei Fragen zu dieser Datenschutzrichtlinie kannst du uns über die Kontaktseite erreichen oder eine E-Mail an minoshek@gmail.com senden.
